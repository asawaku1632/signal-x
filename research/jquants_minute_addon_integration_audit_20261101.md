# J-Quants Tick + OhlcMin 接続・研究導入監査 (2026-11-01)

## 確認した公式仕様
- 契約者申告: Tick + OhlcMin アドオン利用中、税込5,500円/月。API資格情報の接続成功は未確認。
- API: GET https://api.jquants.com/v2/equities/bars/minute
- 認証: x-api-key。APIキーはサーバー環境変数のみで保持し、ログやPRに出力しない。
- クエリ: code または date 必須。期間指定は code + from/to。
- レスポンス: data[] に Date, Time, Code, O,H,L,C,Vo,Va。pagination_key で継続取得。行順は保証されない。
- データ: 東証現物株の1分足、過去2年。出来高ゼロの分はレコードがない。OHLCは分割調整前。
- 更新: 営業日16:30頃の日次更新。**当日9:05のリアルタイムシグナルには使えない**。
- アドオンAPI制限: 60リクエスト/分。大量取得にはCSVを優先。
- 公式: https://jpx-jquants.com/ja/spec/eq-bars-minute / https://jpx-jquants.com/ja/spec/data-spec / https://jpx-jquants.com/ja/spec/data-update / https://jpx-jquants.com/ja/spec/rate-limits

## 研究導入の安全条件
1. 最初は単一銘柄・単一過去営業日で認証・レスポンス・ページングを確認する。ユーザーのAPIキーは会話に貼らせない。
2. 取得時刻・データ日付・提供元・取得ジョブID・スキーマ版を保存し、元データは上書きせず研究用領域に隔離する。
3. CodeはJ-Quantsの5文字コード（普通株は末尾0）を4文字の既存コードに正規化する際、元コードを必ず保持し、英字コードを破壊しない。
4. Date+TimeをJSTで解釈し、重複バー、時刻逆転、OHLC矛盾、負の出来高、欠損分、株式分割を検査する。
5. 09:05判定では**09:05までに確定したバーのみ**を使用。09:05開始の1分バーは09:06以降確定するため、時刻境界を厳格にする。
6. 1分足から5分足を作るとき、時間帯境界・昼休み・15:30板寄せを混同しない。取引のない分を架空のゼロ出来高バーとして補完しない。
7. 翌日寄付・指値・逆指値の約定可能性を分けて検証し、同日引け値を引け後生成シグナルの約定価格として扱わない。
8. 研究観測の作成時刻とバーの利用可能時刻を区別する。歴史データを後日取得したバックテストは「事後再現」と表示し、当時実際に利用可能だったという主張をしない。
9. 研究条件の比較は月別・相場別・銘柄別・アウトオブサンプルで評価し、将来情報混入と多重検定を確認する。
10. 優位性が確認されるまで本番判定・通知を変更しない。追加課金、実売買、無断本番書き込みは行わない。
