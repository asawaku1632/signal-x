# AI実績の損益表示について

既存の `累計損益` は実口座の運用利益ではなく、各判定について `（翌営業日価格 - 保存時価格）×100株` を合算したAI学習検証値です。

新しい `10万円運用シミュレーション` はこれと分離し、元手10万円・追加資金なし・100株単位・AI POWER 85以上のみを対象に、保存時価格で購入して翌営業日価格で売却した仮定で資金を繰り越します。

現行の学習データには利確・損切りライン到達までの価格経路が保存されていないため、利確/損切りまで保有する実運用バックテストとは表示しません。将来OHLCまたはライン到達履歴を保存した段階で、その方式へ拡張します。
