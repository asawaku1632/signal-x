# Favorite result notification behavior

A WIN/LOSE notification describes the outcome of a previously stored favorite AI monitor. Its entry price, take-profit and stop-loss belong to that historical monitor.

The ordinary `/analysis/{code}` page describes the current scan result and can legitimately have a different AI POWER, price, take-profit, stop-loss or judgement.

Therefore result Web Push notifications open a dedicated historical-result page first. Users can then intentionally navigate to the current AI analysis or current chart.
