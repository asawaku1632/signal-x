# Incident: 2026-09-24 Android chart failure

## Symptom

Android chart pages rendered but chart data failed to load. Runtime logs in the Android production project showed `GET /api/chart/...` returning HTTP 405.

## Recovery

The Android TWA was confirmed to use `signal-x-ppjg.vercel.app`. The corresponding Vercel project is `signal-x-ppjg`. Promoting the known-good `a1cc86e` deployment in that project restored chart display.

## Operational lesson

The separate Vercel project `signal-x` is not the Android TWA production target. Checking or promoting that project does not validate or repair Android production traffic.

## Follow-up

- Preserve historical monitor context when opening WIN/LOSE notifications.
- Improve intraday chart freshness only through Preview verification before production promotion.
