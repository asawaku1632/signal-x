# 翌朝参考買値・約定可能性検証（研究仕様）

## 目的
前夜に表示した参考買値が翌営業日に到達可能だったかを、後知恵なしで評価する。価格が届かなかった場合も、後の値動きと区別して記録する。実注文は行わない。

## データ
- code、対象営業日、前夜計算日時、参考価格、参考価格の種類（overnight_statistical_limit / other）
- 元データの最終日、取得元、ライセンス・鮮度・品質状態、計算ロジックのバージョン
- 翌営業日の始値、高値、安値、終値、取得時刻、データソース、確定/暫定区分
- 翌1/3/5営業日終値（確認可能な場合のみ）
- 任意のユーザー申告約定情報は市場価格検証と別に保管する

## 判定
- 翌営業日安値 <= 参考買値なら「日足上は到達」。ただし実約定を保証しない（板・注文順・特別気配・取引停止・市場制度等）。
- 安値 > 参考買値なら「未到達」、差額と差率を記録。
- 日足が不明、古い、未確定、無許諾なら「判定不能」。推測補完しない。
- 約定率という表現は実注文ログがある場合のみ。日足ベースは「価格到達率」とする。
- 未来データや後日の修正を前夜の計算に混ぜない。全件の母数と欠損数を表示。
- 前夜参考価格を後から変更しない。バージョンを保存して再計算と分離する。

ユーザー提供スクリーンショット（9:19時点）では始値3585円、高値3605円、安値3555円、未約定注文100株。**当日最終結果ではない**。前夜の実際の画面ラベルと価格算出根拠は要照合。市場データとして自動確定しない。

## 実装順序
1. 既存の overnightBuyLimit とデータライセンス境界を調査
2. 管理者専用・研究DB隔離のスキーマと重複防止キーを設計
3. 前夜の計算結果をスナップショット保存、翌営業日以降に日足照合
4. データ不足時 fail-closed、未来参照防止、テスト追加
5. 管理者画面で到達率・未到達幅・後日騰落率を表示
6. 承認・CI・権限確認後に段階的に有効化

禁止: 無許諾株価の継続取得、架空の足、リアルタイム約定の断定、研究データからの自動発注。
